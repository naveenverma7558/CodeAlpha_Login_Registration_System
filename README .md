Login and Registration System Using C++

About the Project

This project is a simple Login and Registration System developed using C++ as part of the CodeAlpha C++ Programming Internship.

It allows users to register with a username and password and log in using their registered credentials.

Features

- User Registration
- User Login
- Username Validation
- Password Verification
- File Handling to store user information
- Menu-driven interface

Technologies Used

- C++
- Visual Studio Code
- GCC Compiler

How to Run the Program

Step 1: Compile the Code

Open the VS Code terminal and run:

g++ login_system.cpp -o login_system.exe

Step 2: Run the Program

.\login_system.exe

Sample Output

===== LOGIN SYSTEM =====
1. Register
2. Login
3. Exit

Registration successful!

Login successful!
Welcome, naveen123!

Learning Outcomes

Through this project, I practised:

- C++ functions
- Loops and conditional statements
- Strings and user input
- File handling
- Basic login validation

Security Note

This is a beginner-level demonstration project. Passwords are stored in plain text, so real or sensitive passwords should not be used.
